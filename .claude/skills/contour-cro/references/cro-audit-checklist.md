# CRO Audit Checklist for Self-Service SaaS

This checklist provides a systematic framework for auditing and optimizing landing pages focused on self-service signup conversion.

## Priority Framework

Audit items are ranked by typical impact on conversion rates for B2B SaaS:

**🔥 Critical (50-120% lift potential)**: Form optimization, headline clarity, mobile experience
**⭐ High (20-50% lift potential)**: CTA copy, trust signals, page speed
**✓ Medium (5-20% lift potential)**: Social proof placement, visual hierarchy, feature presentation

---

## 🔥 Critical Elements

### Above-the-Fold (First 5 Seconds)

**Value Proposition Test**
- [ ] Headline answers "What is this?" in <10 words
- [ ] Headline emphasizes outcome/benefit, not feature
- [ ] Subheadline provides specific context (WHO it's for, WHAT problem)
- [ ] Value proposition mentions measurable outcome (%, $, time saved)
- [ ] Hero section is self-contained (no scrolling needed to understand offering)

**Target Audience Clarity**
- [ ] Visitor knows within 3 seconds if this is for them
- [ ] Specific industry/role mentioned if targeting niche
- [ ] Explicit mention of company size/type (enterprise, SMB, etc.)
- [ ] Pain point resonates immediately with target buyer

**Primary CTA**
- [ ] One clear primary action above the fold
- [ ] CTA uses action-oriented, benefit-focused copy (not "Submit" or "Sign Up")
- [ ] CTA button high contrast with background
- [ ] CTA button minimum 48px height for mobile
- [ ] No competing CTAs above fold (remove navigation, links, secondary actions)

### Form Optimization (Highest Impact Change)

**Form Field Audit**
- [ ] Collect ONLY name and email at signup (120% lift potential)
- [ ] No phone number field (major conversion killer)
- [ ] No company name/size fields at signup (gather post-conversion)
- [ ] Password requirements shown upfront if account creation
- [ ] No CAPTCHA at initial signup (use honeypot instead)

**Form Experience**
- [ ] Single-column layout (never multi-column)
- [ ] Clear field labels above inputs (not placeholder text)
- [ ] Inline validation with helpful error messages
- [ ] Submit button text reinforces value ("Start free trial" not "Submit")
- [ ] Progress indicator if multi-step (avoid multi-step when possible)

### Mobile Experience (60-83% of Traffic)

**Critical Mobile Tests**
- [ ] All text readable without zooming (16px minimum body text)
- [ ] Touch targets minimum 48x48px with 8px spacing
- [ ] No horizontal scrolling on any device
- [ ] Forms usable without zooming (proper viewport meta tag)
- [ ] CTA thumb-reachable (bottom 1/3 of screen or floating)
- [ ] Page loads <3 seconds on 3G connection

**Mobile-Specific Optimization**
- [ ] Hero image optimized/compressed for mobile
- [ ] Minimal text entry required (pre-fill when possible)
- [ ] Phone keyboard type matches field (email, number, tel)
- [ ] No hover-dependent functionality
- [ ] Navigation simplified or hidden behind hamburger

## ⭐ High-Impact Elements

### Page Speed

**Performance Benchmarks**
- [ ] First Contentful Paint <1.8s
- [ ] Largest Contentful Paint <2.5s
- [ ] Total page load <3s
- [ ] Time to Interactive <3.8s

**Quick Wins**
- [ ] Images compressed (WebP format, TinyPNG)
- [ ] Critical CSS inlined
- [ ] JavaScript deferred or async
- [ ] CDN for static assets
- [ ] Lazy loading for below-fold images

### Trust & Credibility Signals

**For New Category/New Player** (Critical for Contour SEO)
- [ ] Founder/team credibility prominently displayed
- [ ] Relevant background/expertise highlighted (SEO experience, AI/ML background)
- [ ] Beta/early access framing (if applicable) - "Join 100+ companies testing"
- [ ] Industry recognition or press mentions (even small ones count)
- [ ] LinkedIn profiles linked for transparency

**Social Proof Elements**
- [ ] Customer logos (even 3-5 early adopters)
- [ ] Specific testimonials with full name + company + photo
- [ ] Usage stats ("Join X companies using...") if available
- [ ] Industry-specific social proof (SEO blogs, marketing sites)

**Risk Reduction**
- [ ] "No credit card required" if truly free trial
- [ ] Money-back guarantee prominently displayed
- [ ] Cancel anytime messaging
- [ ] Data security/privacy badges (SOC 2, GDPR if applicable)
- [ ] Clear pricing (even if "Contact us") - no hidden fees surprise

### Call-to-Action Optimization

**CTA Copy Formulas**
- **Action + Benefit**: "Start Ranking in AI Overviews"
- **Action + Time**: "Get Citations in 30 Days"
- **Action + Fear Reduction**: "Try Free for 14 Days"
- **Action + Outcome**: "Boost AI Overview Visibility"

**CTA Placement**
- [ ] Primary CTA above fold
- [ ] Secondary CTA after features section
- [ ] Final CTA after social proof/testimonials
- [ ] Exit-intent popup CTA (if not annoying)

**Visual Treatment**
- [ ] High contrast button color (not brand color if low contrast)
- [ ] Sufficient white space around button
- [ ] No borders or shadows that make it look disabled
- [ ] Hover state clearly different

---

## ✓ Medium-Impact Elements

### Visual Hierarchy

**Attention Flow**
- [ ] Eye naturally flows to headline → value prop → CTA
- [ ] F-pattern or Z-pattern layout respected
- [ ] Adequate white space (not cramped)
- [ ] Headlines 2-3x larger than body text
- [ ] Key benefit callouts visually distinct (color, size, spacing)

**Color Usage**
- [ ] Primary action color used ONLY for CTA
- [ ] Sufficient contrast ratios (WCAG AA minimum)
- [ ] Color not sole indicator (accessible to colorblind)

### Feature/Benefit Presentation

**Content Structure**
- [ ] Benefits before features (outcome before mechanism)
- [ ] "Why this matters" after each feature
- [ ] 3-5 key benefits maximum above fold
- [ ] Specific numbers/metrics when possible
- [ ] Comparison to status quo ("vs. manual SEO research")

**Visual Aids**
- [ ] Screenshots showing actual UI/results
- [ ] Before/after comparisons if applicable
- [ ] Data visualizations for complex benefits
- [ ] Icons to aid scanning (but not decorative clutter)

### Copy Quality

**Readability**
- [ ] 8th-grade reading level maximum
- [ ] Short paragraphs (2-3 sentences)
- [ ] Short sentences (15-20 words maximum)
- [ ] Active voice throughout
- [ ] Scannable with bold/lists

**Voice & Tone**
- [ ] Consistent tone (professional/casual/technical)
- [ ] Second person ("you" not "users")
- [ ] Confident but not arrogant
- [ ] Addresses objections preemptively

### Footer & Secondary Elements

**Footer Must-Haves**
- [ ] Privacy policy link
- [ ] Terms of service link
- [ ] Contact information
- [ ] Social media links (if active)
- [ ] Company information/about link

**What to Remove**
- [ ] Navigation menu (consider removing entirely)
- [ ] Multiple competing links
- [ ] Sidebar distractions
- [ ] Auto-play videos
- [ ] Pop-ups before 10 seconds

## Conversion Psychology Checklist

### For GEO/AI Overview Buyers

**Fear of Missing Out (FOMO)**
- [ ] Mention early mover advantage in AI search
- [ ] Reference competition getting cited in AI Overviews
- [ ] Urgency around AI search evolution ("Before it's too late")
- [ ] Limited spots/beta access if applicable

**Authority & Expertise**
- [ ] Technical depth signals (not simplistic)
- [ ] SEO industry terminology used correctly
- [ ] Reference to AI models/tech (shows understanding)
- [ ] Case studies showing AI Overview ranking improvements

**Risk & Uncertainty Management**
- [ ] Acknowledgment that GEO is new/emerging
- [ ] Positioning as expert guide in uncertain territory
- [ ] Education-first approach (not just sales)
- [ ] Transparency about what's known/unknown

## Technical Checklist

### Analytics & Tracking
- [ ] Google Analytics 4 installed
- [ ] Conversion goals configured
- [ ] UTM parameters on all marketing links
- [ ] Event tracking on CTA clicks
- [ ] Form submission tracking
- [ ] Scroll depth tracking

### Testing Infrastructure
- [ ] Heatmap tool installed (Hotjar, Microsoft Clarity)
- [ ] Session recording enabled
- [ ] A/B testing platform or method defined
- [ ] Baseline conversion rate established

### SEO Fundamentals
- [ ] Title tag optimized (<60 chars)
- [ ] Meta description compelling (<155 chars)
- [ ] H1 tag matches headline
- [ ] Schema markup for organization
- [ ] Open Graph tags for social sharing
- [ ] Canonical URL set

---

## Priority Action Framework

After completing audit, prioritize fixes using this framework:

### Immediate (Do First)
1. Fix form fields (reduce to name + email only)
2. Optimize mobile experience (if <3s load time or usability issues)
3. Clarify headline/value proposition (if fails 5-second test)
4. Fix primary CTA (copy + placement + design)

### Short-term (Do This Week)
5. Add trust signals for new category
6. Implement page speed optimizations
7. Install analytics and tracking
8. Set up heatmap/session recording

### Ongoing (Continuous)
9. Test headline variations
10. Test CTA copy variations
11. Gather and add testimonials
12. A/B test major elements

---

## Validation Methods

**Before/After Testing**
- 5-second test (show page for 5s, ask what it does)
- First click test (where do users click first?)
- Conversion rate comparison (track for 2+ weeks)
- Mobile usability test (actual device testing)

**Qualitative Feedback**
- User interviews (ask "What's stopping you from signing up?")
- Exit surveys (why didn't you convert?)
- Customer interviews (what almost stopped you?)
